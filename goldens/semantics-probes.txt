## E1 — sign of zero through Float.round (value-rounding, spec §6.10/§12.5)
# Negative non-zero inputs that round to zero yield +0.0; only an exactly
# -0.0 input keeps its sign. (Spec §12.5 as written yields -0.0 for the
# former — wrong.)
Float.round(-1.0e-4, 3)  = 0.0   (sign bit 0)
Float.round(-1.0e-7, 6)  = 0.0   (sign bit 0)
Float.round(-0.0, 3)     = -0.0  (sign bit 1)
Float.round(-0.125, 3)   = -0.125  (nonzero results keep their sign)

## E3 — float_to_binary(decimals:) is NOT the exact-binary rounding rule
# at last-ulp-near-half boundaries (spec §6.10 "one rule everywhere").
# The exact binary value of the 5.0e-7 double lies strictly BELOW the
# half point at 6 decimals (the §12.5 exact rule formats "0.0"), but the
# oracle's formatter double-rounds through f64 multiplies and prints
# 0.000001. Value-rounding (Float.round) IS the exact rule — the two
# disagree on exactly this class of input.
Float.round(5.0e-7, 6)                         = 0.0
float_to_binary(5.0e-7, decimals: 6)           = 0.000001
float_to_binary(5.0e-7, [:compact, decimals: 6]) = 0.000001
